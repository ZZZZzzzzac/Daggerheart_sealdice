# 匕首之心原生人物卡

沿用此前数值布局，展示角色名、头像、六特质、资源、闪避/阈值、经历与三种金币。种族、社群、职业、等级、装备、职业特性、卡牌、物品和笔记已移除。使用SealChat已有原生人物卡HTML接口，不需要频道嵌入窗或修改宿主。

## 安装与使用

1. Dice安装/启用自有zac/daggerheart 0.4.7，重载包；在频道中绑定自己的角色并`.set dh`。
2. 根目录`npm run build:sheet`，将`dist/daggerheart.html`上传/设置为人物卡模板，所有角色使用同一份HTML。
3. PbDH“导出为海豹骰”的同一条`.st`包含数值及经历，粘贴到自己角色绑定的频道录卡；0.4.4起全部受支持数值字段保留明确的0，旧卡被省略的零值须按实际数据重录。
4. 等待宿主回读`DH经历`，卡上显示经历，不需要文件导入或角色专属模板。
5. 点击特质骰子，在掷骰窗勾选适用经历；修正累加，每项消耗1希望，希望不足时不能掷骰。插件执行时再次检查当前经历和余额，先支付费用，再结算本次希望收益。反应掷骰也支付经历费用。

每次导入替换整份经历列表，最多5项、名称1–60字、修正-20至20整数；空列表清空经历。海豹骰导出按原有流程录入数值，不读取/上传图片或其他参考资料。经历只读，修改后重新从PbDH导出并录卡。

`npm run build:sheet`只构建通用HTML，不接收存档。`.dh exp`查看，`.dh exp clear`清空；`.st clr`也会清除经历。常规`.st show`隐藏经历JSON，导出仍可能包含它。

## 通信与限制

ROLL_DICE/template发送完整`.dd/.ddr/.st`命令。经历随PbDH导出的原生`.st`保存，资源增减仍用相对`.st`，不使用整卡UPDATE_ATTRS。勾选发送经历索引及内容版本，插件读取当前值，资料改变时拒绝旧选择。头像使用Chat现有功能。

原生接口最终走普通聊天，无静默或执行回执，以Dice回复为准。宿主约10秒回读，Dice属性约60秒周期落盘，异常退出可能丢失未保存修改。窗口展示卡未必等于当前聊天身份绑定卡，操作前确认身份与绑定。插件去重依赖稳定消息rawId，不能承诺跨设备去重、与外部.st的严格并发或原子切卡保护。

## 可选嵌入窗与验收

`daggerheart-embed.html`仅为可选频道iForm入口；经历同样存在Dice属性，不使用共享Storage或附件上传。需要context.read、characters.read、characterCard.read和messages.send，使用自己的活动匕首之心卡。

`npm run test:sheet`和`npm run preview:sheet`。原生预览只读提取固定Chat快照的真实IframeSandbox注入代码，测试替身只在预览页，不进入发布HTML。浏览器验证多经历勾选、零值、费用不足拦截及重开；未把模拟验收称为完整Chat联动。插件官方未修改1.6.1隔离验收见开发指南，生产未部署。

3D动画使用机器人回复中的真实d12/d6注解。宿主需开启3D；当前接口不支持希望骰/恐惧骰分别着色，未改宿主。

资源不显示槽位方块，每卡标签、数字与按钮同排。金币三卡同排：把/袋/箱，上限10/10/1；字段为金币把/金币袋/金币箱，可从PbDH导出或用.st录入。缺失金币点数字明确录入，旧金币字段不自动兑换。HTML不显示恐惧或任意附加属性。
