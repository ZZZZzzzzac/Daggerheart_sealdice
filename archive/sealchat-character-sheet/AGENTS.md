# 历史人物卡参考

本目录是用户要求从 VPS 仓库 Git 历史恢复的旧人物卡，以及用户指定的车卡器皮肤快照。来源和字节 SHA-256 见 manifest.json。

- git-snapshot 和 character-generator-skin 文件只读，保持原字节，不编辑、不格式化、不部署、不导入新实现。仅提取功能、字段与通信需求。
- private 中的旧角色示例属于本地参考，整目录忽略，不上传 Git，不把角色内容写入公共文档。
- 新模板在 sealchat 下从零编写，统一契约见 ../../docs/CHARACTER_STATE.md。
- 历史说明中的部署路径、插件安装指令和资源算法不代表当前系统。
