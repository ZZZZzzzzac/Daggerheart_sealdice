# sealpack 功能与文案审阅清单

依据：正式 iframe 路线的 zac/daggerheart 0.5.0 源码。核对日期：2026 年 10 月 5 日。本清单对应本轮已经实现的代码，替代0.4.12审阅稿；功能、回复和备注保留原编号，删除项明确标记。错误编号按本版重新整理。

包含命令、游戏模板、帮助、掷骰与资源回复、全部45条不同的自有错误提示、商店信息。PbDH按钮、连接面板、掷骰助手以及SealChat窗口文字属于其他界面；原生.st写入、.r伤害掷骰、.sn昵称及.set通用回复由宿主编写，单独注明边界。

功能用F编号，回复用M编号，错误用E编号，审阅备注用R编号。你可以直接指定编号改文案。占位符表示动态值，代码块保留原文。

## 功能清单

### 启用与掷骰

| 编号 | 功能和入口 | 当前行为 |
| --- | --- | --- |
| F01 | .set dh / daggerheart / 匕首之心 | 切换同一游戏模板，关联daggerheart扩展。普通默认骰面设为20；.dd/.ddr明确使用两枚d12。 |
| F02 | 独立使用 | .dd/.ddr无需Chat、PbDH登录或关联、.dh init以及完整资源卡。数字公式可直接用，属性名读取Dice当前卡。 |
| F03 | 帮助 | .dd help/帮助、.ddr help/帮助共用M02；.dh help/帮助使用M03。help不区分大小写，帮助词必须是唯一参数。 |
| F04 | .dd 动作掷骰 | 希望d12 + 恐惧d12 + 算式修正 + 抵消后优劣势d6；未写算式修正为0。 |
| F05 | .ddr 反应掷骰 | 相同二元骰、优劣势、难度和成败规则；不自动获得希望/恐惧，不因关键成功清压力；显式希望费用仍支付。 |
| F06 | 算式与额外骰 | 使用原生.r同一DiceScript引擎，算式只求值一次；支持数字、属性、括号、多属性、额外骰与宿主支持的函数。拒绝赋值/分号语句。只展示附加算式及小计，未逐枚展开其内部额外骰。 |
| F07 | 取高取低 | 取高k/kh/h，取低q/kl/l，如3d12h1、3d12l1。h/l转换为kh/kl；字符串和属性名不转换。 |
| F08 | 优势与劣势 | adv/优势/优，dis/劣势/劣；可带来源数，如adv2、劣势3。每参数1–20来源，总来源不超过40。先抵消，剩余优势加一枚d6，剩余劣势减一枚d6，不按来源数叠骰。 |
| F09 | 难度 | dc15或[15]，只能指定一次；非负安全整数，总数等于难度也成功。未给难度只显示希望结果或恐惧结果。 |
| F10 | 二元骰结果 | 希望骰较大为希望结果，恐惧骰较大为恐惧结果；相同为关键成功，优先于难度。修正/优劣势不改变二元骰比较。 |
| F11 | 原因与上下文 | 独立--后文字展示在第一行。传统属性从算式识别；iframe将属性、经历名称放在原因中。说明文字不验证经历规则适用性。 |
| F12 | hope / hopeN | hope与hope1支付1，hope2支付2；范围0–5，hope0不付费，只能指定一次。不使用等号。先付费再结算，缺少希望或余额不足时拒绝。普通数值修正不会自动扣费。 |
| F13 | 旧pbdh=UUID | 已移除。iframe发送前仍通过官方SDK读DH来源确认当前人物卡，正常掷骰命令没有UUID。 |

```text
.dd
.dd 敏捷+2 adv dc15 -- 攀爬
.dd (敏捷+力量)*2
.dd 敏捷+2+1d6-4+2d6k1-3d12l1
.dd 敏捷 adv2 dis1 [15] -- 攀爬
.ddr 本能 dc14 -- 避开坠石
.dd 3+2 hope adv dc15 -- 知识 · 世界旅行者
```

### 自动结算

| 编号 | 功能 | 当前行为 |
| --- | --- | --- |
| F14 | 玩家希望 | 动作希望结果或关键成功+1。已有希望字段才自动写，缺失改提示手动。按当前卡希望上限封顶；缺失上限默认6，上限允许0–60。超出上限的奖励在资源行显示溢出点数。 |
| F15 | 玩家压力 | 动作关键成功清1压力，最低0；缺失字段改提示手动。不因一般失败自动加压力。 |
| F16 | GM恐惧 | 动作恐惧结果给指定GM当前群绑定人物卡恐惧+1，上限12；缺失恐惧从0创建；未指定GM提示手动。超额奖励在资源行显示溢出点数。 |
| F17 | 其他资源 | 生命、护甲、金币不因.dd/.ddr自动变化，仍使用原生.st。生命、压力、护甲表示已标记槽，希望为可用点数。 |

希望、压力、GM恐惧独立生效，不要求完整人物卡。相关掷骰前校验已有希望/上限、压力和GM恐惧字段，不合规会拒绝掷骰。结算校验不等于给原生.st所有写入加上同一范围约束。

## 帮助与成功文案原文

### M01 模板启用提示

```text
.dd：动作掷骰；.ddr：反应掷骰。
```

这是模板的追加提示，宿主可能在前后附自己的规则切换文案。

### M02 dd与ddr帮助

```text
.dd / .ddr [算式] [adv/dis] [dc难度] [hope费用] [-- 原因]
例：.dd 敏捷+2+2d6h1 adv dc15 hope -- 攀爬
.dd：动作掷骰；.ddr：反应掷骰。
hope 花费1希望，hope2 花费2希望；费用为0–5，先支付再结算。
经历在 iframe 中选择；手输时把经历加进算式并写希望费用。
取高 k/kh/h，取低 q/kl/l。属性与资源用 .st；GM 用 .dh gm；失败恢复用 .dh recover。
```

### M03 dh帮助

```text
.dh gm：查看GM昵称与恐惧
.dh gm me：自己担任GM
.dh gm set 用户ID：指定GM；.dh gm clear：卸任
.st 恐惧+1：调整GM自己的恐惧
.dh recover：恢复未完成的操作，勿重投
.dh pbdh：由 iframe 初始化关联，无需 .dh init。
```

## 掷骰回复原文

### M17 第一行

```text
【{人物名}】{动作掷骰/反应掷骰} · {属性} · {经历} · {原因} · {优劣势}
```

不存在的属性、经历、原因省略。经历由iframe放入原因，插件不从Dice经历数据生成片段。优劣势有4种文字：普通、优势、劣势、优劣势抵消。

iframe数值公式的属性/经历名称来自原因，例如“知识 · 世界旅行者”。

### M18 第二行

```text
希望{骰面}[1d12]+恐惧{骰面}[1d12]+({算式})[{小计}]+优势{骰面}[1d6]={总数} {比较符} 难度{DC} ⇒ **{结果}**
```

劣势片段是“-劣势{骰面}[1d6]”。无优劣势、无修正时省略各自片段；无难度时省略比较符与难度。比较符为>、=、<。

| 编号 | 条件 | 当前结果文案 |
| --- | --- | --- |
| M18a | 希望骰较大、达到难度 | **✅【希望成功】** |
| M18b | 希望骰较大、未达到难度 | **❌【希望失败】** |
| M18c | 恐惧骰较大、达到难度 | **✅【恐惧成功】** |
| M18d | 恐惧骰较大、未达到难度 | **❌【恐惧失败】** |
| M18e | 二元骰相同 | **✨【关键成功】** |
| M18f | 希望骰较大、未设难度 | **◆【希望结果】** |
| M18g | 恐惧骰较大、未设难度 | **◆【恐惧结果】** |

结果两侧实际输出两个星号，支持该语法的界面显示粗体。二元骰/优劣势骰有实际骰面注解；额外算式仅显示小计。

### M19 第三行

统一前缀“资源：”。先费用，再希望/压力/恐惧变化，最后手动结算；片段间分隔符为“ ｜ ”。

| 编号 | 场景 | 当前原文模板 |
| --- | --- | --- |
| M19a | 无变化 | 资源：无变化 |
| M19b | 支付希望 | 希望消耗{费用} |
| M19c | 希望变化 | 希望{之前}→{之后} |
| M19d | 希望无净变化 | 希望{当前}/{上限}；有超额奖励时附（溢出{点数}点） |
| M19e | 压力清除 | 压力{之前}→{之后} |
| M19f | 压力已为0 | 压力0 |
| M19g | GM恐惧变化 | 恐惧{之前}→{之后} |
| M19h | GM恐惧已满 | 恐惧12/12（溢出1点） |
| M19i | 未录入希望 | 手动：希望+1 |
| M19j | 未录入压力 | 手动：压力-1 |
| M19k | 未指定GM | 手动：恐惧+1 |
| M19l | 关键成功、多项未托管 | 手动：希望+1、压力-1 |

### 按真实格式器生成的例子

骰面为审阅用固定示例，未发送真实聊天。人物“哈罗”、知识3、本能2和资源前值均为示例数据。

动作掷骰，希望成功：

```text
【哈罗】动作掷骰 · 知识 · 回忆秘闻 · 优势
希望9[1d12]+恐惧5[1d12]+(知识+2)[5]+优势4[1d6]=23 > 难度15 ⇒ **✅【希望成功】**
资源：希望2→3
```

iframe含经历费用，恐惧失败，已指定GM：

```text
【哈罗】动作掷骰 · 知识 · 世界旅行者 · 劣势
希望5[1d12]+恐惧9[1d12]+(3+2)[5]-劣势4[1d6]=15 < 难度18 ⇒ **❌【恐惧失败】**
资源：希望消耗1 ｜ 希望3→2 ｜ 恐惧5→6
```

反应掷骰，恐惧成功：

```text
【哈罗】反应掷骰 · 本能 · 普通
希望5[1d12]+恐惧9[1d12]+(本能)[2]=16 > 难度14 ⇒ **✅【恐惧成功】**
资源：无变化
```

关键成功，总数低于难度：

```text
【哈罗】动作掷骰 · 普通
希望2[1d12]+恐惧2[1d12]=4 < 难度19 ⇒ **✨【关键成功】**
资源：希望2→3 ｜ 压力2→1
```

无难度、未录入希望：

```text
【哈罗】动作掷骰 · 普通
希望9[1d12]+恐惧5[1d12]=14 ⇒ **◆【希望结果】**
资源：手动：希望+1
```

## 与本地主线的差异

对比本地主线0.4.7，本版新增hope/hopeN显式费用、按卡希望上限结算、.dh pbdh中文JSON关联与姓名/徽标同步、三行掷骰回复与溢出提示。传统.dd/.ddr、原生.st、GM与恢复继续保留。HTML人物卡、Dice经历协议和旧金币模板字段移除；模板与sealpack版本统一0.5.0。

本清单依据当前源代码，公开豹仓状态须由发布入口核对。升级旧版关联标记需在iframe重新关联一次，之后可重连。旧数据不自动删除，可按需使用宿主.st del清理。
