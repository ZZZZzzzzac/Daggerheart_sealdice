# 匕首之心实现范围

## 当前方案

采用PbDH iframe，废弃SealChat HTML人物卡。只使用官方Embed/API、插件、sealpack与原生规则模板，不修改或重新编译SealChat/Dice宿主。实验版本0.5.0，生产发布另行授权。

## 核心包

.dd/.ddr使用固定d12二元骰、原生算式、六特质、来源抵消后单枚d6优劣势与可选难度。取高k/kh/h，取低q/kl/l；未给难度显示希望结果/恐惧结果，关键成功优先。希望费用hope或hopeN，0–5，先支付后结算。不需要.dh init。

动作希望结果/关键成功给已有玩家希望+1，按卡上限，缺失上限默认6；关键成功清已有压力1；恐惧结果给指定GM当前群人物卡恐惧+1，上限12。饱和收益在资源行显示溢出。反应无动作收益但仍支付费用。金币箱0–1，把/袋0–9。

.dh gm me/set/clear管理GM，.dh gm显示昵称和恐惧；.dh recover恢复未完成的操作，最近100条稳定消息回执去重。.st show/list保留0并隐藏内部字段/恐惧，金币聚合为一行。原生.st负责其余资源录入、增减与导出。

## iframe人物卡

PbDH保存属性、经历、职业、装备与完整存档。六特质和武器🎲按钮打开助手；属性/经历转成数值公式，费用通过hope/hopeN发送。Dice不保存经历，移除.dh exp、exp=和pbdh=参数。非iframe玩家手动写数值修正和费用；PbDH海豹骰导出只包含数字。

首次.dh pbdh关联初始化姓名、资源/上限、金币与徽标字段，保存DH来源/DH姓名；后续按变化字段.st同步并回读确认，重连不初始化。云存档、导入、市场导航和登录沿用PbDH原系统，不加手动写云端按钮。武器伤害用原生.r，不自动扣生命或护甲。

## 边界与未提供能力

不提供援助授权扣他人希望、旧行动计数器、盛宴/烹饪、规则速查库或GM恐惧技能菜单。旧金币不转换；旧经历不读取。GM恐惧保存在人物卡，不另建群资源池。徽标使用SealChat现有能力。

没有原子绑定/跨库事务/严格外部.st并发保证；保存周期和突然进程退出仍影响持久化。完整正式域名登录、嵌入响应头和发布环境需要上线验收。本地测试、官方隔离宿主验收与当前限制分别见DEVELOPMENT.md和CHARACTER_STATE.md。
