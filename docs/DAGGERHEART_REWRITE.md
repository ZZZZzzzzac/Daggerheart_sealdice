## P1：sealpack核心（当前）

目录 sealdice/packages/daggerheart。功能：.dd/.ddr、数字/额外骰修正、六特质、来源抵消后的单枚优劣势骰、显式DC和原因、经历修正与资源结算提示。固定d12二元骰，关键成功优先于难度；未给DC不编造成功/失败。0.2.0使用原生.st作为属性/资源入口，无.dh init门槛；资源完整且指定GM时自动结算，否则正常投骰并提示手动处理。加入.dh动态资源操作与频道GM恐惧池，经历可按稳定ID读现有字段并扣费，尚无.pbcha导入。

P1基础包已在隔离官方Windows 1.6.1实例完成安装、启用、.set dh、真实Goja的.dd/.ddr与特质读取、禁用/启用重载和卸载验收；11项本地测试通过。没有连接生产或IM账号，尚未验证Chat联动。运行实例中存在旧同名指令时先停用旧包。

## P2：SealChat人物卡（尚未实现）

新建自有 HTML 模板，不沿用旧UI。先解决基础易用性：六特质一键检定，行动/反应、难度、修正和优劣势清晰可选；希望和已标记生命/压力/护甲槽各自独立；阈值、闪避、熟练、经历、装备与笔记从PbDH .pbcha导入并只读显示；静态编辑与升级在PbDH完成。金币纳入动态资源，重新导入保护当前资源。生命/压力使用已标记槽的语义，避免把剩余生命与已标记生命混用。

已从VPS Git历史恢复旧在线人物卡，并保存车卡器皮肤只读快照，见 archive/sealchat-character-sheet。资源由Dice当前频道绑定卡保存，Chat只作展示与操作入口。现有UPDATE_ATTRS路径会发送整份缓存属性，不能直接依赖它安全写资源；自定义.dd也不在当前自动刷新命令列表。新读写流程、字段语义和并发验收见 [CHARACTER_STATE.md](CHARACTER_STATE.md)。旧代码仅提取需求，不迁移。
