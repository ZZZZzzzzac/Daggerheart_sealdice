# 匕首之心原生扩展包

- 从零编写；只阅读旧文件提取功能与需求，不导入、复制或移植旧实现。
- 仅使用 SealDice 已提供的插件与 sealpack 接口，遵守根 AGENTS.md 的二次开发硬约束；禁止修改宿主源码、制作或应用源码补丁、重编译修改版宿主。接口不足须说明限制并调整方案。
- 正式版核心规则使用官方 SRD 2.0 核心部分；扩展内容独立可选。
- info.toml 为包元信息入口，脚本与独立 V2 YAML 模板一同打包。新增资源明确列入构建白名单。
- rules.mjs 不依赖宿主；main.mjs 只负责 SealDice 接口。不要在 JS 中重新注册包内模板。
- 普通.dd与.st独立于Chat可用，无初始化门槛；希望/压力字段存在时独立结算，缺失提示手动结算；托管资源由当前Dice属性保存。资源写回先校验、保留恢复意图，仅写玩家自己的希望/压力及指定GM当前绑定卡的恐惧；GM身份按频道保存，不建独立恐惧池。经用户授权，.dh exp额外单字段写入玩家当前绑定卡的DH经历，最多5项名称/修正，不保存其他PbDH资料或图片。勾选经历每项自动扣1希望；希望不足/经历版本变化在投骰前拒绝，扣费沿用去重/恢复。不能宣称跨库事务或外部.st/character.set并发安全。
- npm run build && npm test；测试含规则、宿主模拟和产物检查，模拟不能代替实际宿主验收。
- 0.1.0基础已通过隔离真实1.6.1；新版本须重新验收；不自动上传生产，不修改 reference，不代发聊天。

- iframe 实验分支可接收 hope=0–5 本次费用和 pbdh=存档 UUID；数值公式不依赖 DH经历。投骰前核对 DHPbDH来源，费用与奖励复用同一去重/恢复流程；资源上限遵循当前卡的希望上限，未录入仍默认6。此能力仅本地实验，不自动发布。

- iframe 初始化用 .dh pbdh 接收可读的中文 JSON 白名单数据并兼容旧 URI 编码；使用官方 rawArgs 保留原始姓名，整串解析拒绝尾随数据，先校验完整资源、UUID 与姓名。通过官方 seal.vars 与 Goja 玩家上下文更新昵称/保存标记，DHPbDH姓名 和 DHPbDH来源 供回读确认；不访问人物卡管理器，不改写绑卡元数据。不得把带连字符的 UUID 放在原生 .st 开头。
