# 匕首之心 sealpack · 0.3.0

属性与资源统一用原生 .st；无需 Chat、.dh init、完整资源或静态上限。

## 开始使用

在 SealDice 1.6.1 及以上上传、安装、启用并重载包；停用旧同名插件。

    .set dh
    .st 敏捷2 希望2 压力0
    .dd 敏捷 +2 adv dc15 -- 攀爬
    .ddr 本能 dc14
    .st 希望-1 压力+1

希望与恐惧各一枚d12，相同出目关键成功。未写难度不判断一般成功/失败。adv/dis按来源抵消后至多一枚d6；支持数字和附加骰修正，原因写在独立的 -- 后。

## 自动结算

- 玩家希望存在：希望结果或关键成功自动+1，上限6。
- 玩家压力存在：关键成功自动-1，最低0。
- 指定了GM：恐惧结果给GM在此群当前绑定卡的恐惧+1，上限12；缺少恐惧时从0开始创建。
- 各项独立生效，不依赖生命、护甲、金币或上限。缺失的玩家字段不创建，仅提示手动结算。
- .ddr不产生希望、恐惧或清压力；经历仍先扣希望。

六属性默认0；希望/压力/恐惧的默认表达式null表示未设置，确保初次.st 希望0 / 压力0真实存入卡中。.st del 希望可退出希望自动结算。生命、压力、护甲表示已标记槽，希望为可用点数。

## GM

    .dh gm claim
    .dh gm set SEALCHAT:完整用户ID
    .dh gm clear
    .dh gm
    .st 恐惧0
    .st 恐惧+1

首次指定需要群管理权限；现任GM或群管理员可交接、卸任。GM身份按群保存；恐惧只保存在GM当前人物卡，没有插件独立池。修改.st后下一次.dd读取最新值。交接不复制原GM卡的恐惧，不同群绑定同一GM卡会共享卡上恐惧；需隔离时绑定不同卡。

.dh公开帮助只含GM操作，不再提供资源增减、fear、status、experience、rule。.dh recover保留为写回失败时的维护入口。

## 经历

.dd 敏捷 exp:e1 dc15读取DH经历字段，每项先扣1希望，只需希望字段存在且余额足够。内部为JSON字符串列表，条目含id/name/value；PbDH导入尚未实现，暂用数字修正并.st手动处理费用，不接受旧expN。

## 升级与恢复

0.2.x的GM身份保留，旧群恐惧池不自动复制到任何人物卡。升级前记下旧.dh fear数值，升级后由GM .st 恐惧N录入。未完成旧写入先在0.2.1执行.dh recover。旧模板省略的默认希望2、压力0不视为字段存在；升级后按真实数值重新.st录入。

恢复验证原玩家和GM的卡标识及字段前后值，不覆盖外部.st冲突。稳定rawId存在时最近100次操作去重。意图日志与人物属性不是跨库事务，不锁住外部.st/character.set；属性约60秒保存，突然结束进程可能丢失未保存内容。卸载不删除人物资源。

## 开发与范围

src/rules.mjs包含规则和掷骰/结算文案；src/main.mjs包含帮助、GM命令、人物卡读写及恢复；src/state.mjs包含独立字段结算；templates/daggerheart.yaml包含模板及.st展示。npm test / npm run build生成dist，不直接修改产物。

27项测试；tools/native-smoke.py用隔离官方1.6.1验收缺失/零值字段、另一个用户的GM卡、经历、重载、重启及卸载，不接IM或生产。没有网络/HTTP/文件读写权限。Chat人物卡、PbDH导入、昵称标签与完整术语库尚未实现。
