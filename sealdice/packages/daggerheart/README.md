# 匕首之心 sealpack 0.5.0

本地 iframe 实验版。SealChat 人物卡采用 PbDH iframe，旧 HTML 人物卡与 Dice 经历协议已移除。同一个 zac/daggerheart 包仍可在其他平台手输 .dd/.ddr，不依赖 SealChat 或 PbDH 登录。

## 开始使用

在未修改的官方 SealDice 1.6.1 及以上安装并启用本包，停用旧同名插件，然后：

    .set dh
    .st 敏捷2 希望3 希望上限6 压力0
    .dd 敏捷+2 adv dc15 hope -- 攀爬 · 山野向导
    .ddr 本能 dc14
    .st 希望-1 压力+1

无需 .dh init。iframe 首次明确关联由 .dh pbdh 初始化联动资源；同一存档重连只回读 Dice，不再次初始化。其他平台使用具名特质时可通过 PbDH“导出海豹骰”主动录入数字快照；经历不导出，手输时将修正加进算式并写希望费用。

## 掷骰与费用

.dd 是动作掷骰，.ddr 是反应掷骰。希望与恐惧各一枚 d12，相同出目关键成功，优先于难度。dc15 或 [15] 指定难度，总数达到难度成功；未给难度只显示希望结果或恐惧结果。

adv/dis 或优势/劣势按来源抵消，最终至多一枚 d6。adv2 表示两项优势来源，单参数来源数1–20，总来源数不超过40。

算式通过官方 DiceScript 求值一次。取高支持 k/kh/h，取低支持 q/kl/l，例如2d6k1、2d6kh1、2d6h1和3d12q1、3d12kl1、3d12l1。h/l转换为kh/kl，不影响字符串或属性名。支持括号、多属性、数值、额外骰与宿主已有函数；不接受赋值或语句。原因放在独立 -- 后。

hope 或 hope1 花费1希望，hope2 花费2，以此类推；费用范围0–5，hope0不支付。不支持hope=语法。希望不足、未录入希望或算式无效在投骰前拒绝。先付费用，再结算动作奖励。普通数字修正不自动收费。

回复固定三行：人物/动作或反应/属性与经历说明/优劣势；公式、实际二元骰/优劣势骰和加粗结果；费用与资源变化。附加算式显示小计，不逐枚展开其内部额外骰。

    【哈罗】动作掷骰 · 知识 · 世界旅行者 · 劣势
    希望5[1d12]+恐惧9[1d12]+(3+2)[5]-劣势4[1d6]=15 < 难度18 ⇒ **❌【恐惧失败】**
    资源：希望消耗1 ｜ 希望3→2 ｜ 恐惧5→6

没有难度时末尾是 **◆【希望结果】** 或 **◆【恐惧结果】**。希望/恐惧已满仍获得点数时，在资源行注明溢出点数，例如希望6/6（溢出1点）。

伤害掷骰使用宿主原生 .r，iframe 武器助手只生成熟练值个伤害骰加固定值的公式，例如 .r 3d6+3 改良巨杖。

## 自动结算与人物卡

- 动作希望结果或关键成功：已有玩家希望+1，按当前卡希望上限封顶；上限未录入默认6，允许0–60。
- 动作关键成功：已有玩家压力清1，最低0。
- 动作恐惧结果：指定GM当前群绑定人物卡的恐惧+1，上限12；GM未录入恐惧从0创建。
- 缺失玩家字段不自动创建，未托管的收益提示手动结算。反应掷骰不产生上述奖励，但希望费用仍支付。
- 生命、护甲、金币不自动结算；资源增减通过原生.st。生命、压力、护甲表示已标记槽，希望表示可用点数。

模板用null区分未录入和明确的0。六特质、四项资源/上限、闪避、阈值与金币单位保留0；旧版本省略的0需重新录入。

.st show/list只显示已录入的白名单整数，每行4项。金币单独显示为金币：1 把 0 袋 1 箱，未知单位用?；不显示恐惧、旧金币字段或内部标识。金币把/袋/箱仍分别保存，别名把/袋/箱；不自动兑换。iframe关联/读取/步进按9/9/1边界校验，原生.st其他操作沿用宿主行为。

## GM

    .dh gm me
    .dh gm set SEALCHAT:完整用户ID
    .dh gm
    .dh gm clear
    .st 恐惧+1

首次指定需要群管理权限，现任GM或群管理员可交接/卸任。回复使用当前人物卡昵称，例如GM：本地GM ｜ 恐惧4/12。平台用户ID仅作为指定命令的输入，不显示在正常GM回复中。

GM身份按群保存，恐惧保存在GM当前绑定人物卡；交接不复制恐惧。多群绑定同一人物卡会共享卡上恐惧，需要隔离时使用不同人物卡。

## iframe关联与升级

PbDH持有属性、经历、职业、装备和人物存档，账号/本地保存/云同步沿用PbDH正常系统。Dice只接收资源副本、金币、闪避/阈值以及DH来源与DH姓名确认标记。.dh pbdh接受中文JSON并兼容旧URI编码，校验完整白名单后更新当前玩家昵称，不改绑卡管理器元数据。资源上限0–60，金币箱0–1；闪避/阈值0–1000000。

本版移除.dh exp、exp=、pbdh=、旧金币/gold模板字段以及.dh gm claim。旧经历/旧金币等宿主已存数据不解释、不迁移；原生.st可以按需删除。关联标记由旧DHPbDH字段改为DH来源/DH姓名，升级后的实验会话需要重新关联一次。此后关闭重开可重连。

## 失败恢复

.dh recover只用于尚未完成的掷骰资源写入或GM变更，不重新投骰。插件先保存本次骰面、回复和写入前后值，再写希望/压力/GM恐惧，完成后记录消息回执并清除待办。

部分保存失败会提示：保存失败，请执行 .dh recover，勿重投。原玩家在同一群/私聊、原人物卡执行恢复；涉及GM时GM也需使用原人物卡。字段若已是操作后值不会再次扣费；仍是操作前值则补上；既不是前值也不是后值，拒绝覆盖并提示联系骰主。

有稳定rawId时最近100条操作去重。恢复意图与人物属性不是跨库事务，不能锁住外部.st；属性落盘受宿主约60秒保存周期影响，突然终止进程可能丢失未保存状态。恢复不撤销已完成掷骰、不还原云存档、不接管.dh pbdh初始化。卸载不主动删除人物资源。
